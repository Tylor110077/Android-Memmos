Memmos 安卓配套软件 — 设计方向画廊

贴边捕捉滑块 + 小红书剪藏功能面板。三个方向共享同一套信息架构（待机 / 拖拽吸附 / 识别帖子 / 语音感想 / 抓取进度→完成 / 浮条设置），仅视觉语言不同。点击卡片打开对应方向的完整 HTML 原型（横向滚动浏览全部六帧）。

DIRECTION A

琉璃 Glass

深色玻璃拟态 + 小红书红橙渐变。待机时呼吸微光、低存在感；面板像浮起的磨砂玻璃，覆盖任何宿主 App 都不打架。消费级质感，最「潮」。
